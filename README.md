# WordleFetch
## A simple way to get information on todays wordle

## Setup

### Clone the repository
```bash
git clone https://github.com/WordleFetch
cd WordleFetch
```
### Install rich
```bash
pip install rich
```
### Run the python file
```python
python Run.py
```

### Optional, Enable alias 
run the setup.sh script so you can type wordle anywhere to run the python script
```bash
chmod +x Setup.sh
./Setup.sh
```
